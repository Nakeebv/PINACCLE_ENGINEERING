# PINACCLE_ENGINEERING

Official website for **Pinnacle Engineering** — *Engineering the Future. Building What's Next.*

A cinematic, dark-mode marketing experience built around the brand's chrome-on-black
identity with electric blue accents.

## Stack

- **React 19** + TypeScript + **Vite**
- **Tailwind CSS v4**
- **Framer Motion** — scroll, physics & reveal animations
- **Lenis** — buttery smooth scrolling
- **Lucide React** — iconography

## Sections

- **Hero** — "Engineering the Future. Building What's Next." with staggered reveal
- **About** — mission, philosophy & animated stats
- **Core Values** — Innovation · Precision · Reliability · Excellence · Integrity
- **Capabilities** — Advanced Manufacturing, Automation & Robotics, Energy & Infrastructure, Digital Engineering & R&D
- **Vision** — scroll-scrubbed statement reveal
- **Contact** — project inquiries & footer

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
# single-file output → dist/index.html
```
